# Comfortaa variable webfont

These unmodified WOFF2 subset files and their `wght.css` were taken from
[`@fontsource-variable/comfortaa` v5.3.0](https://www.npmjs.com/package/@fontsource-variable/comfortaa)
(Google Fonts Comfortaa v47). Comfortaa is copyright the Comfortaa Project
Authors and is distributed under the [SIL Open Font License 1.1](OFL.txt).

Keyfall embeds them as an offline fallback for the separately licensed Torus
font. `scripts/build.mjs` substitutes an internal CSS family alias and data URLs;
it does not change the font files. The userscript and plain bundle also include
the full font license in a readable comment.
